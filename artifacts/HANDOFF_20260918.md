## 二、当前可用状态（含验证方式）

### 2.1 Pop! Slots 老虎机数值采集 —— **可用**

- 路线：**Frida 挂引擎内的 curl 边界**（不是代理、不是 hook TLS）。
  实测依据：引擎**不读 Android 全局代理**（进程持有 5 条活跃 :443 连接时，到代理 0 条连接）；
  引擎导出的 `SSL_write` 被 Frida hook 命中 0 次（流量走 curl），而 `curl_easy_setopt` 是真实实现且可命中。
- 实测结果（`P2/MGM`）：8 次转盘 → 总下注 400,000、总中奖 110,000、**实测 RTP 27.5%**、
  中奖率 2/8、最大单次 100,000。**样本极小，不能当期望值。**
- 本地数据（**不入 Git**）：`C:\bigfish_research\popslots_run_20260918\`
  （`slots_values.csv` 逐次数值、`slots_summary.md` 汇总、`pop_net.jsonl` 原始、`autoplay.jsonl` 点击留痕）
- 一条命令验证链路：见 §6.1。
- ⚠️ **消耗口径**：接口 URL 里的 `bet` 是**每线**下注，实际每次消耗 = `lines × bet`
  （实测 `lines=20, bet=2500` → **每次 50,000**）。跑自动转盘前先看 SPIN 按钮上的数字。

## 五、坑清单（这次踩到的，全部已修/已记录）

| 现象 | 根因 | 处理 |
|---|---|---|
| 脚本在 cmd 里满屏 `'ist' 不是内部命令`、双击无反应 | **`.cmd` 写成 LF 行尾**，cmd.exe 需要 CRLF | 改 CRLF + 正文纯 ASCII + 更稳的 Python 探测 |
| `--help` 在非 UTF-8 控制台崩溃 | reconfigure 写在 `parse_args()` **之后**，而 `--help` 在解析期就退出 | 改为**导入时**重配 stdout/stderr |
| adb 输出被本地化文本打断、真实错误被 `NoneType` 掩盖 | `text=True` 走本地码页解码 | `encoding="utf-8", errors="replace"` + `or ""` 兜底 |
| PowerShell 往返改文本把 UTF-8 文件写成乱码 / BOM | `Get-Content \| Set-Content` 的编码往返 | **不要**用 PowerShell 往返改 UTF-8 文件；用 Python 字节级读写 |
| `adb devices` 空但实例在跑 | BlueStacks 实例启动后不自动连 adb | `adb connect 127.0.0.1:<端口>` |
| 游戏卡 `LOADING...`、画面黑 | VPN 应用（`com.wonderustech.aurora`）拉起 `tun0` **劫持 DNS**（logcat `ERR_NAME_NOT_RESOLVED`） | `force-stop` + `pm disable-user` + 恢复 `net.dns1` |
| `check` 报 frida-server 不可达 | 实例重启后设备侧进程消失 | 重跑 `setup-frida`（用本地文件，不重下 110MB） |
| Ghidra 脚本报 `NumberFormatException` | **Ghidra 会把脚本参数按逗号和空格都切开** | 参数按"非数字即关键字"解析；**不要用 `\|` 或逗号拼关键字** |
| 复用 Ghidra 项目又要再等 15 分钟 | 漏了 `-noanalysis` | 复用已分析项目必须加 `-noanalysis` |
| 启动了同名实例把在跑的实例关机 | BlueStacks 抢盘 | **启动实例前必须先正向确认身份**（已写进 `AGENTS.md`） |
